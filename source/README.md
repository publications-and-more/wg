# Ne.app Working Groups/Data Number/Task Number Groups.

#### This README indexes the different working groups and their purpose.

## Working Groups:

The Working Groups are paper(s) owned by a group of persons in which they improve or work at.

### Active Working Groups:

- WG01: `The NeKernel Group`.
- WG02: `The Systems Group`.
- WG03: `The Nectar Group`.
- WG04: `The Mathematics Group`.
- WG05: `The Execution Theory Group`.
- WG06: `The Debugging Group`.
