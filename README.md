# The NeSystem Papers Collection.

## Abstract:

This is the Working Group papers of Ne.org
<br/>
Refer to [`CITATION.cff`](CITATION.cff) if you wish to cite these documents.

## Getting Started:

Please fork and clone the repository first:

```sh
git clone git@github.com:<your-username>/papers.git
```

## Requirements:

- LiveTeX (htlatex, pdflatex)
- Git
- CoreUtils
- Extra TeX packages, scientific, etc.

## Recommended Tools:

- Use `pdflatex` for PDF generation.
- Use `Overleaf` to edit the LaTeX files.
