## Getting Started:

Please fork and clone the repository first:

```sh
git clone git@github.com:<your-username>/draft.git
```

## Requirements:

- LiveTeX (htlatex, pdflatex)
- Git
- CoreUtils

## Recommended Tools:

- Use `pdflatex` for PDF generation.
- Use `Overleaf` to edit the LaTeX files.
